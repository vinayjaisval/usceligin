🚀 Reusable Tooltip Component System

Modern, accessible, CSS-only tooltips for CELIGIN platform

📍 Tooltip Positions

ℹ️ Info Button Style (Used in Sign-in)

🎨 How to Use

<!-- Basic Tooltip -->
<div class="tooltip-wrapper">
  <button class="tooltip-trigger">
    Hover me
    <div class="tooltip-content">
      Tooltip text here
    </div>
  </button>
</div>

<!-- Position Variants -->
<div class="tooltip-wrapper tooltip-bottom">...</div>
<div class="tooltip-wrapper tooltip-left">...</div>
<div class="tooltip-wrapper tooltip-right">...</div>

<!-- Info Button Style -->
<button class="tooltip-trigger info-btn">
  <svg>...</svg>
  <div class="tooltip-content">Info text</div>
</button>

✨ Features

  • 🎯 CSS-only - No JavaScript required
  • ♿ Accessible - Works with keyboard navigation
  • 📱 Responsive - Adapts to screen size
  • 🌙 Dark mode ready - Automatic theme support
  • 🔧 Reusable - Use anywhere in the platform
  • ⚡ Performant - Minimal CSS footprint
