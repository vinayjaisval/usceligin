✨ Features

  • ✅ 20px gap - As requested, with proper left alignment
  • ♿ Fully accessible - Screen reader and keyboard navigation support
  • 🎯 Click anywhere - Label, box, or text all toggle the checkbox
  • ⌨️ Keyboard support - Space and Enter keys work
  • 🎨 Visual feedback - Hover, focus, and checked states
  • 📱 Mobile friendly - Touch-optimized interaction area
  • 🔧 Reusable - Use anywhere in the platform

🔧 JavaScript Integration

The checkbox component works with standard JavaScript:

// Get checkbox value
const checkbox = document.getElementById('keepSignedIn');
console.log(checkbox.checked); // true/false

// Set checkbox value
checkbox.checked = true;

// Listen for changes
checkbox.addEventListener('change', (e) => {
  console.log('Checkbox is now:', e.target.checked);
});
