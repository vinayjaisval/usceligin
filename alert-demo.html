🎨 How to Use

<!-- Basic Alert Structure -->
<div class="alert alert-{type}" role="alert" aria-live="polite">
  <svg class="alert-icon">...</svg>
  <div class="alert-content">
    <div class="alert-title">Title</div>
    <div class="alert-message">Message</div>
  </div>
</div>

<!-- Alert Types -->
alert-info     - Blue info alerts
alert-success  - Green success alerts
alert-error    - Red error alerts
alert-warning  - Orange warning alerts

<!-- With Error List -->
<div class="alert alert-error" role="alert" aria-live="assertive">
  <svg class="alert-icon">...</svg>
  <div class="alert-content">
    <div class="alert-title">Validation Errors</div>
    <ul class="alert-list">
      <li>Error message 1</li>
      <li>Error message 2</li>
    </ul>
  </div>
</div>

♿ Accessibility Features

  • ARIA Live Regions - aria-live="polite" for info/success, aria-live="assertive" for errors
  • Role="alert" - Semantic role for screen readers
  • Keyboard Navigation - Focusable with proper tab order
  • Color Contrast - WCAG AA compliant colors
  • Icon + Text - Information conveyed through multiple channels
  • Semantic HTML - Proper heading hierarchy and lists

🔧 JavaScript Integration

For dynamic alerts, use these utility classes:

  • .alert.hidden - Hide alert
  • .alert.visible - Show alert
  • .alert-enter / .alert-enter-active - Entry animation
  • .alert-exit / .alert-exit-active - Exit animation
